## 📖 درباره پروژه

**ادب‌دوست** (Adab Doost) یک ربات تلگرامی پیشرفته و هوشمند است که با قدرت هوش مصنوعی **Google Gemini** توسعه یافته است. این ربات تنها یک چت‌بات ساده نیست، بلکه یک آتلیه هوشمندی برای خلق شعر، تحلیل ادبی و جستجو در اعماق دنیای واژگان است.

ربات با پایگاه داده قوی SQLite و رابط کاربری مدرن (Inline Keyboards) طراحی شده تا تجربه‌ای بی‌نظیر برای عاشقان ادبیات فارسی فراهم کند.

---

## ✨ ویژگی‌های شاهکار

ربات ادب‌دوست با امکانات پیشرفته‌ای که دارد، یک ابزار کامل برای ادب‌دوستان است:

*   🎨 **آتلیه شعر:** تولید انواع اشعار از سبک‌های کلاسیک (غزل، مثنوی) تا شعر نو و ترانه.
*   🔍 **تریبون تحلیل:** تحلیل عمیق متون ادبی و شعرها با تمرکز بر آرایه‌های ادبی و مضامین.
*   🎛 **تنظیمات هوشمند:**
    *   انتخاب **سبک** (Style): غزل، شعر نو، مثنوی، ترانه.
    *   انتخاب **حال و هوا** (Mood): عاشقانه، حماسی، غمگین، شاد.
    *   تنظیم **سطح تخیل** (Temperature): از منطقی تا کاملاً خلاقانه.
*   🔄 **موتور بازسازی (Remix):** قابلیت بازنویسی خلاقانه آخرین اثر با لحنی متفاوت.
*   💾 **پایگاه داده دائمی:** تمام تنظیمات کاربران در دیتابیس SQLite ذخیره می‌شود.
*   📡 **ارتباط پایدار:** استفاده از Proxy اختصاصی برای دسترسی به هوش مصنوعی جمنای.
